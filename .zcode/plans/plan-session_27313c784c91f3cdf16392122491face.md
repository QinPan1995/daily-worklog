# 顶部区域改版 — 先出原型比稿（暂不开发正式版）

## Context
用户喜欢下方的事项卡网格（A 方案），希望重新设计**上方区域**（标题行 + 统计卡 + 近 7 天图表卡 + 添加栏），要求先出几版原型图选择，选型后再实施。已确认：整个顶部层级可重排、视觉可以放开做（允许大数字冲击、光晕渐变、深色 hero）。

## 第一阶段：原型比稿（本次执行）
工作区新建 **`layout-top-preview.html`**（独立预览页，不影响正式版 daily-worklog.html）：
- 复用现有 Anthropic 色板、衬线字体变量、深浅双主题机制和卡片样式语言
- 用真实感示例数据（1 个运行中任务、1 个暂停、若干已完成、近 7 天有时长分布）静态渲染，顶部 segmented control 切换 + URL hash 直达

四版方案：
| 版本 | 设计 | 特点 |
|---|---|---|
| V1 焦点舞台 | 运行中任务上浮为 hero 大卡（衬线大标题+超大计时器+暂停/结束），下方一条紧凑统计行，近 7 天变内联 sparkline；配深色/光晕大胆表达 | 层级重排最大，"一次专注一件事"叙事，空闲时 hero 变引导 |
| V2 单条统计带 | 统计+图表合并为一条矮横卡：今日投入大数字 + 进行/完成小指标 + 内联 7 日迷你柱状图 | 页面最短，网格最早出现 |
| V3 左右仪表盘 | 一张大卡内部左右分栏：左=今日投入大数字+完成数，右=近 7 天柱状图 | 保持现有卡片感，纯布局重排 |
| V4 极简单行 | 统计与 sparkline 压进标题行，统计卡图表卡全部取消 | 最激进最简洁 |

执行步骤：写预览页 → 浏览器（8123 本地服务器）打开 → 逐版截图（浅色为主、大胆版加深色截图）→ AskUserQuestion 展示截图让用户选型（可混搭、可提修改意见）。
