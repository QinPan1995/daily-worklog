# 🐱 每日工作台（Daily Worklog）

> 小满风格宠物主题的单文件计时记录工具 —— 零依赖、零安装，双击即用。

一只毛绒小恐龙陪你记录每天的工作：打开页面它在跟你打招呼，干活时它骑着目标进度条等你，忘记暂停它会提醒你，写日报时它帮你把数据整理好。

## ✨ 功能

- **⏱ 计时记录**：添加事项即开始计时，支持暂停 / 继续 / 结束；同一时刻只走一个表，切换自动暂停
- **🐱 宠物陪伴**：打招呼、眨眼、挥手、躲猫猫、骑进度条——小恐龙陪你记录每一天（纯手绘 SVG，无外部图片）
- **📊 统计卡片**：今日投入、较昨日增减、连续天数、每日目标进度（默认 8h，可设置）、近 7 天趋势
- **📄 一键日报**：自动把当天记录拼成可复制的汇报文本，粘到飞书 / 企微直接用
- **🕘 工作时间管理**：可配置上午 / 下午上班时间段，统计自动剔除午休和下班后，到点自动暂停
- **💾 数据备份**：JSON 备份导出 / 导入（支持合并与覆盖），CSV 导出可用 Excel 打开
- **🌙 深浅双主题**：奶油橙浅色 / 暖棕深色，一键切换
- **🔍 事项补全**：输入事项名时自动提示历史名称

## 🚀 使用

1. 下载 `daily-worklog.html`
2. 双击用浏览器打开（推荐 Chrome / Edge）
3. 在顶部输入框输入事项名，回车开始计时

> 所有数据保存在浏览器本地（localStorage），建议定期在「备份」中导出 JSON 文件。

## 🛠 技术说明

- 纯原生 HTML + CSS + JavaScript，**单文件、零依赖、可离线使用**
- 计时基于时间戳计算，刷新 / 关闭浏览器不会丢失或错乱
- 无框架、无构建步骤、无网络请求
